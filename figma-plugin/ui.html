使用说明

  • 确保 Figma 文件中有 Export Assets（图片资源）或 文字资源_ Frame
  • Export Assets 下的子 Frame 名称 = OSS 路径
  • 图层名称 = 文件名（必须包含扩展名）
  • 文字资源 Frame 下的 TEXT 节点 = JSON 字段

常见问题

  • 未找到资源：检查 Frame 命名是否正确
  • 导出失败：检查节点是否被锁定或隐藏
  • 上传失败：检查网络连接和 API 配置
  • 验证错误：检查文件名格式和特殊字符
