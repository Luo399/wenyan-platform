## 四、怎么复查（结果会变，别照抄本文）

```bash
# 一张表看全：覆盖矩阵 + 引用完整性 + 归属（串台/text_id/篇名）+ 孤儿卡片视频 + 设计页面图
bash scripts/check-asset-correspondence.sh

# 顺带把每篇的标题图下到 /tmp/article-titles/，人工核对「编号 ↔ 篇名」
FETCH_TITLES=1 bash scripts/check-asset-correspondence.sh

# 只看前 5 篇，快速自检脚本本身
POEM_COUNT=5 bash scripts/check-asset-correspondence.sh
```

脚本按「引用归属」判串台的规则：素材名一律以 `WEN_nn_` 开头，取名字里的编号与所在 JSON 的编号比对，
不等就是给别的课文挂素材。目前这一项 0 告警（因为 05–37 根本没有 JSON）。
退出码非 0 的条件：有取不到的引用 / 有串台或 text_id 不一致 / 篇名不一致。
